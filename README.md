# JARVIS 1.0

Prima versione PWA del progetto JARVIS per iPhone e iPad.

## Cosa include
- Interfaccia mobile/futuristica
- Chat
- Risposta vocale tramite speechSynthesis
- Input vocale quando il browser lo supporta
- Manifest PWA
- Struttura pronta per collegare il backend AI

## Importante
Questa versione è un prototipo frontend: non contiene ancora API key né un backend AI.
Non inserire mai una chiave API privata dentro i file pubblici della PWA.

## Pubblicazione
Può essere pubblicata come sito statico, ad esempio con GitHub Pages.
