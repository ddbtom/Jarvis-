# JARVIS 2.0

Nuova interfaccia per iPhone e iPad.

## Importante
Questa build è il frontend. Non inserire mai chiavi API direttamente nei file JavaScript pubblici.

## Integrazione con iPhone
La strada più pratica senza Mac è:
1. usare JARVIS come web app/PWA;
2. creare un Comando Rapido chiamato `JARVIS`;
3. richiamarlo con Siri dicendo "Ehi Siri, JARVIS";
4. collegare il Comando Rapido al backend AI quando sarà pronto.

Apple permette a Siri di eseguire i Comandi Rapidi tramite la loro frase/nome. Per una futura app nativa, App Intents permette un'integrazione più profonda con Siri, Spotlight e Comandi Rapidi.
